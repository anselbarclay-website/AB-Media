AB MEDIA EASY EDITOR — PHOTO + VIDEO VERSION

Public site: https://abmediaco.netlify.app
Editor: https://abmediaco.netlify.app/admin/
Repository configured: anselbarclay-website/AB-Media (main branch)

NORMAL WORKFLOW
1. Open the editor URL and log in with GitHub.
2. Open Website Content.
3. Under Fashion, Property, or Music Gallery, add an item.
4. Choose Type = Photo or Video.
5. For Photo: upload the Photo field.
6. For Video: preferably paste a YouTube/Vimeo/direct MP4 URL into Video URL. For a small MP4, Video File can be used.
7. Add an optional caption.
8. Publish. Netlify will redeploy the same public website URL automatically.

IMPORTANT VIDEO NOTE
GitHub is not intended for large video files and blocks individual files over 100 MB. For high-quality portfolio videos, use the Video URL field with YouTube/Vimeo or another hosted direct MP4 URL. This keeps the website repository smaller and the site faster.
