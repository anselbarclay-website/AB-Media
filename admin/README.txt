AB MEDIA WEBSITE — QUICK START

1. Open index.html in Chrome to preview the site.
2. Add your highlight reel:
   videos/highlight-reel.mp4

3. Add homepage cover photos using EXACTLY these names:
   images/fashion-cover.jpg
   images/property-cover.jpg
   images/music-cover.jpg

4. Portfolio photos can go in:
   images/fashion/
   images/property/
   images/music/

5. Open the matching HTML page in a text editor and replace a placeholder with:
   <img src="images/fashion/YOUR-FILE.jpg" alt="Description">

   For video:
   <video controls playsinline>
     <source src="videos/YOUR-VIDEO.mp4" type="video/mp4">
   </video>

6. Change the contact email in index.html:
   Search for hello@abmedia.com and replace it.

7. Change the Instagram button:
   Search index.html for href="#" next to Instagram and paste your profile URL.

FREE HOSTING OPTIONS:
- GitHub Pages
- Cloudflare Pages
- Netlify

You can connect a custom domain after deployment.
